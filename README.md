# GPT-OSS-20B — три интерактивные учебные карты

Учебная карта с пояснениями, карта островов и пространственный атлас помогают исследовать устройство GPT-OSS-20B: компоненты, связи, формы тензоров и проверенные фрагменты обученных чисел.

## Скачать и открыть

**[Скачать три карты одним ZIP — v0.1.1, около 1,1 МБ](https://github.com/katiasmolskaia-hub/gpt-oss-learning-maps/releases/download/v0.1.1/gpt-oss-learning-maps-v0.1.1.zip)**

[Страница релиза и контрольная сумма](https://github.com/katiasmolskaia-hub/gpt-oss-learning-maps/releases/tag/v0.1.1)

1. Скачайте архив по ссылке выше.
2. Распакуйте его целиком в отдельную папку (Windows: правая кнопка по ZIP → «Извлечь всё…»).
3. В распакованной папке **gpt-oss-learning-maps** откройте **index.html** в браузере.

**Не открывайте index.html прямо внутри ZIP:** соседние папки могут остаться в архиве, и при переходе к карте появится ERR_FILE_NOT_FOUND.

Установка и сервер не нужны. Карты работают локально; модель не запускается, полные веса скачивать не требуется. Внешние источники открываются только по нажатию на ссылку.

Используйте ZIP с названием карт. Кнопка Code → Download ZIP скачивает содержимое репозитория, а не учебный пакет; пакет размещён во вложениях релиза.

## Три способа изучения

- **Учебная карта:** от модели к слою, компоненту и поясняющей карточке.
- **Карта островов:** отношения модели, среды, интерфейсов, параметров и оборудования.
- **Пространственный атлас:** общий вид, раздвижение частей, вращение, увеличение и числовые образцы.

Материалы рассчитаны на самостоятельное знакомство и учебные демонстрации. Геометрия условная: она помогает ориентироваться в архитектуре и не изображает физическое расположение на чипе.

Архитектура сверена с [официальным репозиторием OpenAI](https://github.com/openai/gpt-oss) и [репозиторием модели](https://huggingface.co/openai/gpt-oss-20b). Закреплённые ревизии, источники утверждений и методика включены в пакет.
